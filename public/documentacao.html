Tudo que você precisa saber para utilizar a plataforma Aurum com máxima eficiência.

Guias de Início Rápido

Criando sua Conta

  1. Acesse o backoffice da Aurum Foundation
  2. Clique em "Criar Conta" e preencha seus dados
  3. Verifique seu email e ative a conta
  4. Configure a autenticação em duas etapas (2FA)
  5. Complete a verificação de identidade (KYC) se necessário

Primeiro Depósito

  1. Acesse "Carteira" no menu principal
  2. Selecione a criptomoeda que deseja depositar
  3. Copie o endereço de depósito gerado
  4. Envie suas criptomoedas para o endereço
  5. Aguarde as confirmações na blockchain

API Reference

Documentação técnica para desenvolvedores que desejam integrar com a plataforma Aurum.

Autenticação

Todas as requisições à API requerem autenticação via API Key e Secret. Gere suas credenciais no painel da plataforma.

Endpoints Principais

  • GET /api/v1/account - Informações da conta
  • GET /api/v1/balance - Saldos da carteira
  • POST /api/v1/order - Criar nova ordem
  • GET /api/v1/orders - Listar ordens
  • GET /api/v1/trades - Histórico de trades
  • GET /api/v1/ticker - Preços em tempo real

Rate Limits

A API possui limites de requisições por minuto para garantir estabilidade:

  • Endpoints públicos: 100 req/min
  • Endpoints privados: 60 req/min
  • Endpoints de ordem: 30 req/min

Perguntas Técnicas Frequentes

  • Qual o tempo de confirmação de depósito? Depende da blockchain. Bitcoin: 3 confirmações. Ethereum: 12 confirmações.
  • Posso usar a API para trading automatizado? Sim, nossa API suporta integração com bots externos.
  • Como exportar meu histórico de transações? Acesse Configurações → Relatórios → Exportar CSV.
